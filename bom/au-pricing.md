## Phase 0

Use what already exists:

- Maschine Mk3
- iPad as PWA touch controller
- current audio routing/input options
- future Mac Studio when it arrives

## Buying rule

Do not buy hardware to solve an unproven mapping.

A purchase only becomes valid after:

1. one knob changes one sound;
2. the mapping is logged;
3. the limitation is clear;
4. the purchase removes that limitation without creating split-brain complexity.
