# Future Desk Notes

This is parked.

No purchases required for Phase 0.

A hybrid desk may become useful later if the live machine proves itself, but it must not become the first proof.

## Desk role later

A future desk should handle:

- physical inputs;
- clean gain staging;
- monitoring;
- routing;
- returns from the Mac;
- tactile mixing;
- maybe OSC/MIDI control.

## Do not buy early

The desk is not the instrument by itself.

The proof is:

```text
one real input → one mapped control → one audible meaningful change
```

Until that proof works, a desk adds complexity, cost, and cable fog.

## Revisit trigger

Revisit desk decisions only after:

- 8-control Maschine map works;
- one live model is passing audio;
- wet/dry blend is stable;
- latency is logged;
- the system has produced at least three useful experiment logs.
