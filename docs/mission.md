# HARDWAREJUICE Mission

I am building a personal instrument.

It is a hybrid physical-digital system: real audio signal paths on one side, local neural audio models on the other, and tactile controls in between.

The goal is simple and difficult:

To touch something with my hands and have it meaningfully change the feel of sound in ways that matter.

This system is for finger-to-ear emotional control. Not perfect prediction. Not typing prompts during play. Not another screen pretending to be a studio.

## Core belief

The raw audio carries the soul.

A voice, instrument, recording, mistake, breath, loop, stem, or live input remains the primary human signal. The system’s job is to restyle that signal according to what is being chased: memory, pressure, warmth, grit, energy, intimacy, overkill, or some private texture that does not yet have a clean word.

## Playing mode

During play:

- hands should stay on controls;
- ears should judge the output;
- prompts should be generated behind the scenes;
- the system should feel direct, playable, and trustworthy;
- subtle-to-extreme movement should happen in learnable increments.

The local LLM can help translate control state into language, but it is not the instrument. The instrument is the control surface, the audio path, the models, and the ear.

## Research mode

During research and development, the system can expose ugly details: models, latency, failed mappings, bad timbre, broken assumptions, unstable prompts, noisy logs.

That is acceptable.

During playing, that complexity should be hidden behind usable controls.

## Long-term aim

Over time the rig should learn the maker’s private language: what counts as body, air, pressure, sadness, light, menace, rain-on-concrete, too clean, too fake, too much, not enough.

The work is to close the gap between inner feeling and speaker output.

It does not need to be finished.
It does not need to be perfect.
It does not need to be useful to anyone else.

It needs to be started, tested honestly, and built so the process remains playable.
